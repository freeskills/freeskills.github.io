4.2

Organize the repository Organizar o repositório

A folder a stranger could open and understand. That stranger is you next month. Uma pasta que um estranho abre e entende. Esse estranho é você no mês que vem.

Introdução

Quando tudo está na raiz, a IA e você se perdem. Organizar não é “arquitetura”. É achar o JSON, o CSS e o detalhe do apto sem adivinhar.

O que você vai aprender

  • Uma árvore simples para o site da Marina.
  • O que um README de uma página precisa dizer.
  • Commits que descrevem o produto, não o humor.

Por que isso importa

Um repo limpo deixa o próximo pedido (“filtra por bairro”) seguro: a IA mexe no lugar certo.

Pedido

Prompt

Continuamos no site da Marina Alves Corretora. Não redesenhe o visual.

Quero só organizar o repositório:

1) Pastas claras: css/, js/, data/, imoveis/ (páginas de detalhe). Ajuste os caminhos relativos.
2) README.md curto: o que o site é, como abrir local (python3 -m http.server), como adicionar um imóvel no JSON.
3) .gitignore se ainda não existir (nada de .DS_Store, nada de pasta de backup).
4) Não invente framework. Mostre a árvore de pastas antes de mover os arquivos.

Depois eu reviso no navegador (home, catálogo, um detalhe, contato).

Commit útil

Git

git add .
git status
git commit -m "Organiza pastas, README e caminhos do site da Marina"

Se um CSS “sumir”, o caminho relativo quebrou na mudança de pasta. Abra o navegador antes do próximo pedido.

Checklist

  • Há pastas (css, js, data, imoveis) e a home ainda abre.
  • O README diz como servir local e como incluir um apto.
  • O último commit descreve a organização, não “wip”.

Próximo passo

Pastas sem o porquê ainda esquecem. A próxima lição anota as decisões: JSON, sem framework, WhatsApp.

Introduction

When everything sits at the root, you and the AI get lost. Organizing is not “architecture”. It is finding the JSON, the CSS, and the apt detail without guessing.

What you will learn

  • A simple tree for Marina’s site.
  • What a one-page README needs to say.
  • Commits that describe the product, not the mood.

Why this matters

A clean repo makes the next ask (“filter by neighborhood”) safer: the AI edits the right place.

The ask

Prompt

Continuamos no site da Marina Alves Corretora. Não redesenhe o visual.

Quero só organizar o repositório:

1) Pastas claras: css/, js/, data/, imoveis/ (páginas de detalhe). Ajuste os caminhos relativos.
2) README.md curto: o que o site é, como abrir local (python3 -m http.server), como adicionar um imóvel no JSON.

4) Não invente framework. Mostre a árvore de pastas antes de mover os arquivos.

Depois eu reviso no navegador (home, catálogo, um detalhe, contato).

A useful commit

Git

git add .
git status
git commit -m "Organize folders, README, and paths on Marina’s site"

If CSS “vanishes”, a relative path broke in the move. Open the browser before the next ask.

Checklist

  • There are folders (css, js, data, imoveis) and the homepage still opens.
  • The README says how to serve locally and how to add an apt.
  • The last commit describes the organize step, not “wip”.

Next step

Folders without the why still forget. Next, write the decisions down: JSON, no framework, WhatsApp.

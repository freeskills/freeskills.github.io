VPS server Servidor VPS

A Linux server of your own. We use Beway on it for ease: up to 3 free sites and the certificate set up automatically. Um servidor Linux só seu. Usamos a Beway nele pela facilidade: até 3 sites gratuitos e o certificado configurado automaticamente.

Introdução

VPS significa servidor virtual privado: um Linux só seu, com IP próprio, que você liga, atualiza e usa como quiser. É o caminho mais profissional. Você instala a Beway nele pela facilidade: até 3 sites gratuitos no mesmo servidor e o certificado HTTPS configurado automaticamente.

Não afunde na instalação agora se o objetivo é só colocar o primeiro HTML no ar. Esta lição existe para você saber que este é o próximo degrau, não a porta de entrada. Para um site HTML, a hospedagem compartilhada basta.

O que você vai aprender

  • O que uma VPS é (e o que ela não é).
  • Onde contratar: Linode, DigitalOcean, AWS e Google Cloud.
  • Por que usamos a Beway: facilidade, até 3 sites grátis e certificado automático.
  • Quando essa forma deixa de ser opcional.

Por que isso importa

Quando o curso evoluir (sistemas reais, banco, autenticação, deploys mais sérios), a estrutura mínima passa a ser: VPS própria com a Beway instalada. Conhecer os provedores agora evita escolher no escuro depois.

Por que usar a Beway

Dá para publicar numa VPS “na unha”: Nginx, pasta pública, certificado Let’s Encrypt, renovação. A escolha da Beway é outra: o painel cobre isso sem você montar a stack do zero.

  • Facilidade: criar o site no painel e enviar os arquivos.
  • Até 3 sites gratuitos no mesmo servidor.
  • Certificado HTTPS configurado automaticamente quando o domínio aponta para a VPS.

Três sites no plano gratuito já cobrem este módulo e os próximos exercícios. Você não precisa pagar a Beway para começar.

Provedores

Os quatro abaixo cobrem do mais simples ao mais “nuvem grande”. Linode e DigitalOcean costumam ser o começo mais amigável: um plano, um Linux, um IP. AWS e Google Cloud aguentam de tudo, mas o painel tem mais portas. Os links da Linode e da DigitalOcean são de indicação e podem incluir crédito na conta nova.

Linode Hoje parte da Akamai Cloud. Planos claros, data centers no mundo todo, bom ponto de partida. DigitalOcean Droplets simples, documentação direta e uma conta fácil de acompanhar. AWS A nuvem mais usada no mercado. Muitos serviços. Comece por uma instância EC2 se for por aqui. Google Cloud Compute Engine e o resto da GCP. Forte se você já vive no ecossistema Google.

Para o primeiro servidor, um plano Linux barato (1 vCPU, 1 GB de RAM) já sobe a Beway e um site. Não comece pelos produtos mais caros da AWS ou da GCP.

Passo a passo (visão geral)

  1. 1Contrate uma VPS Linux (Ubuntu LTS é uma escolha segura)
  2. 2Anote o IP e o acesso SSH. Guarde a chave, não só a senha do painel.
  3. 3Instale a Beway nessa VPS, seguindo a documentação em beway.io
  4. 4Crie o site no painel e envie o HTML (ou o fluxo de publicação que a Beway oferecer)
  5. 5No registrador, aponte o domínio para o IP da VPS e copie a URL

O detalhe da instalação fica na documentação da Beway. Não invente um painel paralelo agora. O curso volta a essa estrutura quando o projeto deixar de ser só HTML estático.

O domínio nesta forma

Na VPS o apontamento costuma ser um registro A com o IP do servidor. Nameservers do registrador podem continuar os padrão; só o A precisa apontar para a máquina certa. A Beway configura o certificado automaticamente depois que o domínio resolve para o IP.

Checklist

  • Você sabe o que é uma VPS e por que ela é o degrau profissional.
  • Você conhece quatro provedores: Linode, DigitalOcean, AWS e Google Cloud.
  • Você não travou o primeiro HTML esperando configurar um servidor.
  • Você sabe por que a Beway entra: facilidade, até 3 sites grátis e certificado automático.
  • Quando o curso pedir estrutura mínima, o caminho é VPS + Beway.

Introduction

VPS means virtual private server: a Linux box of your own, with its own IP, that you start, update, and use as you like. This is the more professional path. You install Beway on it for ease: up to 3 free sites on the same server and the HTTPS certificate set up automatically.

Do not sink into the install now if the goal is only to get the first HTML page online. This lesson is here so you know it is the next step, not the front door. For an HTML site, shared hosting is enough.

What you will learn

  • What a VPS is (and what it is not).
  • Where to buy one: Linode, DigitalOcean, AWS, and Google Cloud.
  • Why we use Beway: ease, up to 3 free sites, and an automatic certificate.
  • When this path stops being optional.

Why this matters

When the course evolves (real systems, a database, auth, more serious deploys), the minimum structure becomes: your own VPS with Beway installed. Knowing the providers now keeps you from picking in the dark later.

Why we use Beway

You can publish on a VPS by hand: Nginx, a public folder, a Let’s Encrypt certificate, renewals. Choosing Beway is the other path: the panel covers that without you assembling the stack from scratch.

  • Ease: create the site in the panel and upload the files.
  • Up to 3 free sites on the same server.
  • The HTTPS certificate is set up automatically once the domain points at the VPS.

Three sites on the free plan already cover this module and the next exercises. You do not need to pay for Beway to start.

Providers

The four below run from the simplest to the big-cloud end. Linode and DigitalOcean are usually the friendlier start: one plan, one Linux, one IP. AWS and Google Cloud can run anything, but the panel has more doors. The Linode and DigitalOcean links are referrals and may include credit on a new account.

Linode Now part of Akamai Cloud. Clear plans, data centers worldwide, a solid starting point. DigitalOcean Simple Droplets, straightforward docs, and a bill that is easy to follow. AWS The most used cloud in the market. Many services. Start with an EC2 instance if you go this way. Google Cloud Compute Engine and the rest of GCP. Strong if you already live in the Google stack.

For a first server, a cheap Linux plan (1 vCPU, 1 GB RAM) already runs Beway and a site. Do not start with the expensive AWS or GCP products.

Step by step (overview)

  1. 1Get a Linux VPS (Ubuntu LTS is a safe choice)
  2. 2Save the IP and SSH access. Keep the key, not only the panel password.
  3. 3Install Beway on that VPS, following the docs at beway.io
  4. 4Create the site in the panel and upload the HTML (or use the publish flow Beway provides)
  5. 5At the registrar, point the domain at the VPS IP and copy the URL

Install details live in the Beway docs. Do not invent a parallel panel now. The course returns to this structure when the project is no longer just static HTML.

The domain on this path

On a VPS, pointing is usually an A record with the server IP. The registrar’s default nameservers can stay; only the A record needs to hit the right machine. Beway sets up the certificate automatically after the domain resolves to the IP.

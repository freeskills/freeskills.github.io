Our first software Nosso primeiro software

Build a simple static HTML site with AI, register a domain, and publish it. No Skills and no SDD yet: the direct process first. Criar um site HTML estático simples com IA, registrar um domínio e publicar. Ainda sem Skills e sem SDD: o processo direto primeiro.

Introdução

O módulo 1 preparou a mesa. Aqui a gente cozinha: um projeto real, curto e completo o bastante para ir da pasta vazia até uma URL pública.

Skills e SDD ficam para depois de propósito. Antes de formalizar o método, você precisa sentir o ciclo simples: pedir, revisar, alterar, registrar um domínio, publicar.

O que você vai aprender

  • Criar um site HTML estático com ajuda da IA.
  • Pedir alterações sem recomeçar o projeto.
  • Registrar um domínio (.com, .com.br e outras extensões).
  • Publicar em hospedagem compartilhada ou em um servidor VPS.

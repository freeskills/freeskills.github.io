Module 3 Módulo 3

Building a real system Criando um sistema real

Same realtor, same folder. Now the site has to work for a visitor who wants a listing, and for Marina who wants the lead. A mesma corretora, a mesma pasta. Agora o site precisa funcionar para quem quer um imóvel e para a Marina, que quer o lead.

No módulo 2 o site da Marina Alves Corretora foi ao ar: uma landing, um domínio, um publish. Isso ainda é um folheto. Folheto não deixa o visitante abrir um imóvel, nem manda o telefone dela para o WhatsApp com contexto, nem deixa ela incluir um apto novo sem reescrever a home.

Aqui o mesmo projeto vira um sistema pequeno: várias páginas, um catálogo, um contato que chega, dados fora do HTML. Continua sem Skills e sem SDD. O hábito do ciclo curto não muda.

O que você vai aprender

  • O que falta para o site ser útil de verdade.
  • Lista de imóveis e uma página por imóvel.
  • Lead no WhatsApp, sem backend.
  • JSON de imóveis e republicar no mesmo domínio.

Conteúdos deste módulo

In module 2 Marina Alves Corretora went live: a landing page, a domain, a publish. That is still a brochure. A brochure does not let a visitor open a listing, does not send Marina a WhatsApp with context, and does not let her add an apt without rewriting the homepage.

Here the same project becomes a small system: several pages, a catalog, contact that arrives, data outside the HTML. Still no Skills and no SDD. The short-cycle habit does not change.

What you will learn

  • What the site still needs to be actually useful.
  • A listing list and one page per property.
  • A WhatsApp lead, no backend.
  • Listings JSON and a republish on the same domain.

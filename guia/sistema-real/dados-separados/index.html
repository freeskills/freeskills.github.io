3.4

Data apart from the HTML Dados separados do HTML

One JSON file. The homepage and the catalog read it. Um arquivo JSON. A home e o catálogo leem dele.

Introdução

Se o preço está copiado na home, na lista e no detalhe, a Marina erra o terceiro. Dados num JSON são a mesma verdade para as telas que listam.

O que você vai aprender

  • Um formato mínimo de imóvel.
  • Por que o navegador às vezes recusa JSON em file://.
  • Como incluir o sétimo apto.

Por que isso importa

Separar dado de layout é o primeiro passo para o site crescer sem virar um emaranhado.

Pedido

Prompt

Continuamos no site da Marina Alves. Não mude o visual.

Quero os imóveis fora do HTML.

1) Crie data/imoveis.json com pelo menos 6 itens. Campos: id, titulo, bairro, quartos, preco, resumo, destaque (true/false).
2) A lista (imoveis.html) e os 3 destaques da home devem ler esse JSON (JS simples). Se o arquivo não abrir por file://, diga para eu servir a pasta com um servidor local.
3) As páginas de detalhe podem continuar estáticas por enquanto, mas o id no JSON deve bater com o nome do arquivo (ex.: id copa-2q → imovel-copa-2q.html).
4) Não use framework. Mostre o formato do JSON antes de gerar os 6 itens.

Depois explique como eu adiciono o 7º imóvel.

Servir local (se o JSON não carregar)

Terminal

cd ~/projetos/meu-primeiro-site
python3 -m http.server 4174

O detalhe ainda pode ser HTML solto. O ganho agora é lista e destaques lendo a mesma fonte.

Checklist

  • Existe data/imoveis.json.
  • Home e catálogo leem o arquivo (via servidor local se precisar).
  • Você sabe o que editar para entrar o 7º imóvel.

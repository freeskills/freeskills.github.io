3.5

Publish the system again Republicar o sistema

Upload the new pages, the JSON, and the JS. Same domain as module 2. Envie as páginas novas, o JSON e o JS. O mesmo domínio do módulo 2.

Introdução

O domínio já é da Marina. Republicar é enviar o que o navegador precisa agora: HTML novo, CSS, JS, data/imoveis.json. Não é registrar outro nome.

O que você vai aprender

  • O que subir além do index.html.
  • Quando a hospedagem compartilhada ainda basta.
  • Quando a VPS com Beway (até 3 sites grátis, certificado automático) fica mais confortável.

Por que isso importa

Um sistema que só roda no seu computador não existe para o comprador. O ciclo fecha de novo: pasta → URL.

Checklist de envio

  • index.html, imoveis.html, contato.html, páginas de detalhe.
  • CSS, JS e data/imoveis.json (a pasta data precisa ir junto).
  • Caminhos relativos: se o JSON “sumir”, o caminho no JS está errado ou o arquivo não foi enviado.

Qual caminho

HTML + JSON + JS ainda é arquivo estático. Hospedagem compartilhada continua válida. Se você já tem VPS, a Beway publica de novo no mesmo site, com certificado automático e espaço para até 3 sites no plano gratuito.

  1. 1Confira localmente (servidor simples + aba anônima).
  2. 2Envie só o que o navegador lê.
  3. 3Abra o domínio, o catálogo e um imóvel.
  4. 4Mande um lead de teste no WhatsApp.

Checklist

  • O domínio antigo abre o site novo.
  • O JSON carrega no ar (não só na sua máquina).
  • Um lead de teste chegou.

Próximo passo

Com o sistema no ar, o módulo 4 trata do crescimento: pasta bagunçada, decisões e filtros.

Introduction

The domain is already Marina’s. Republishing is uploading what the browser needs now: new HTML, CSS, JS, data/imoveis.json. It is not registering another name.

What you will learn

  • What to upload besides index.html.
  • When shared hosting is still enough.
  • When a VPS with Beway (up to 3 free sites, automatic certificate) gets more comfortable.

Why this matters

A system that only runs on your computer does not exist for the buyer. The loop closes again: folder → URL.

Upload checklist

  • index.html, imoveis.html, contato.html, detail pages.
  • CSS, JS, and data/imoveis.json (the data folder has to come along).
  • Relative paths: if JSON “vanishes”, the JS path is wrong or the file was not uploaded.

Which path

HTML + JSON + JS is still static files. Shared hosting still works. If you already have a VPS, Beway publishes again on the same site, with an automatic certificate and room for up to 3 sites on the free plan.

  1. 1Check locally (simple server + a private window).
  2. 2Upload only what the browser reads.
  3. 3Open the domain, the catalog, and one listing.
  4. 4Send a test lead on WhatsApp.

Checklist

  • The old domain opens the new site.
  • JSON loads online (not only on your machine).
  • A test lead arrived.

Next step

With the system online, module 4 is growth: a messy folder, decisions, and filters.

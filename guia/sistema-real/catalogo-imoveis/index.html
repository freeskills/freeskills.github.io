3.2

Catalog and listing pages Catálogo e páginas de imóvel

Six listings and a URL each. The homepage keeps three highlights. Seis imóveis e uma URL para cada. A home fica com três destaques.

Introdução

Três cards na home cabem num folheto. Um catálogo é uma lista que o visitante percorre, mais uma página em que o apto existe sozinho: dá para mandar o link no WhatsApp.

O que você vai aprender

  • Como pedir várias páginas sem redesenhar o site.
  • O que cada página de imóvel precisa ter no mínimo.
  • Como a home aponta para o catálogo sem perder os destaques.

Por que isso importa

Se cada imóvel só vive num card da home, a Marina não consegue mandar “olha este”. Uma URL por apto muda o uso do site no dia a dia.

Pedido

Prompt

Continuamos no site HTML da Marina Alves Corretora (não recomece do zero). Mesmo visual: fundo #F7F4EF, texto #0B1F33, destaque #2F5D50.

Objetivo: o visitante precisa achar mais do que 3 cards na home.

Faça, nesta ordem, e pare para eu revisar no navegador depois de cada item:
1) Uma página imoveis.html (ou /imoveis/) com uma lista de pelo menos 6 imóveis fictícios na Zona Sul (título, bairro, quartos, preço).
2) Uma página por imóvel (ex.: imovel-copa-2q.html) com descrição curta, preço, bairro e um botão “Falar no WhatsApp”.
3) A home continua com 3 destaques, agora com link “Ver todos os imóveis” e cada card apontando para a página do imóvel.
4) O menu (Início, Imóveis, Contato) precisa funcionar nas páginas novas.

Não use framework. Caminhos relativos. Explique os arquivos novos em poucas frases.

Revisar

  • O menu não quebra nas páginas novas.
  • Cada imóvel tem URL própria.
  • A home ainda abre e os 3 destaques apontam para o detalhe.
  • No celular a lista empilha.

Checklist

  • Existe uma lista com pelo menos 6 imóveis.
  • Você abriu pelo menos uma página de detalhe no navegador.
  • O visual ainda é o da Marina, não um template novo.

Próximo passo

Lista sem contato ainda é vitrine. A próxima lição faz o lead chegar no WhatsApp dela.

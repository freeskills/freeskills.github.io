6.3

Project DNA for the realtor DNA do projeto da corretora

If DNA is missing, SDD starts with init. Here you write who Marina’s site is for. Se o DNA falta, o SDD começa no init. Aqui você escreve para quem o site da Marina existe.

Introdução

DNA é o recorte que segura o resto. Sem ele, a spec do admin vira CRM com dez papéis. Com ele, admin é: só a Marina lista, cadastra, edita e remove imóveis.

O que você vai aprender

  • O que cabe no DNA (atores, é / não é).
  • Como pedir isso à IA com o plugin SDD ligado.
  • Como recusar CRM e portal de classificados que ninguém combinou.

Por que isso importa

Toda feature nova se mede no DNA. Se não cabe, não entra neste recorte.

Pedido

Prompt

Projeto: site da Marina Alves Corretora (HTML + JSON de imóveis, lead no WhatsApp). Skill marina-imovel (só visual) e docs/decisoes.md já existem.

Quero o DNA do produto, curto, em .specs/project/ (ou o caminho que o SDD do FreeSkills usar). Cubra só:

1) Quem usa: comprador na Zona Sul (site público); Marina (corretora, área administrativa).
2) O que o produto é: vitrine + contato + área admin para a Marina listar, cadastrar, editar e remover imóveis.
3) O que o produto NÃO é: CRM, portal tipo ZAP, pagamento, multi-usuário, pedido de visita neste recorte.
4) Restrições: admin não aparece no menu público; senha simples só neste recorte (não é segurança de produção); persistir no estoque (JSON ou o que a spec definir).

Não gere código de feature. Não invente módulos extras além de site público + admin. Escreva o DNA e pare para eu ler.

Leia o arquivo gerado em voz alta. Se aparecer CRM, pagamento ou “módulo de clientes”, corte antes da spec do admin.

Checklist

  • Há um DNA no repo (pasta .specs/ ou a que o plugin criou).
  • Comprador e Marina estão nomeados.
  • Está escrito o que o produto não é.

Próximo passo

Com o DNA no lugar, especifique só a área administrativa: lista, cadastro, edição, exclusão.

Introduction

DNA is the cut that holds the rest. Without it, the admin spec becomes a CRM with ten roles. With it, admin is: only Marina lists, adds, edits, and removes listings.

What you will learn

  • What belongs in DNA (actors, is / is not).
  • How to ask the AI for it with the SDD plugin on.
  • How to refuse a CRM and a classifieds portal nobody agreed on.

Why this matters

Every new feature is measured against the DNA. If it does not fit, it does not enter this cut.

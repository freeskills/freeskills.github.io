6.2

Installing the SDD plugin Instalando o plugin SDD

Marketplace first, then sdd@freeskills. Same home page you already used. Marketplace primeiro, depois sdd@freeskills. A mesma home que você já usou.

Introdução

O SDD do FreeSkills é um plugin, não a Skill marina-imovel. Os dois convivem: o plugin traz o método (.specs/, protocolos); a Skill traz o visual. O admin de imóveis nasce da spec, não da Skill.

O que você vai aprender

  • Os comandos de instalar e conferir.
  • Onde ler a página do plugin.
  • O que esperar depois (pastas .specs/ quando o init rodar no projeto).

Por que isso importa

Sem o plugin, você ainda pode escrever spec à mão. Com ele, a IA segue o protocolo do framework em vez de inventar uma pasta “docs2”.

Instalar

Marketplace (se ainda não fez)

/plugin marketplace add freeskills/marketplace

Plugin SDD

/plugin install sdd@freeskills

A página do plugin está em plugins/sdd. A home do site tem as variantes para Claude Code, Cursor e Codex.

Não rode um “init” em outro repositório por engano. O projeto é ~/projetos/meu-primeiro-site (o da Marina).

Checklist

  • sdd@freeskills aparece na lista de plugins.
  • Você sabe que isso não publica o site sozinho.
  • A pasta aberta na ferramenta é a da Marina.

Próximo passo

Com o plugin no ambiente, escreva o DNA: quem usa o site e o que ele não é.

Introduction

FreeSkills SDD is a plugin, not the marina-imovel Skill. They live together: the plugin brings the method (.specs/, protocols); the Skill brings the look. The listings admin comes from the spec, not from the Skill.

What you will learn

  • The install and check commands.
  • Where to read the plugin page.
  • What to expect after (a .specs/ folder when init runs on the project).

Why this matters

Without the plugin you can still write a spec by hand. With it, the AI follows the framework protocol instead of inventing a “docs2” folder.

Install

Marketplace (if you have not yet)

/plugin marketplace add freeskills/marketplace

SDD plugin

/plugin install sdd@freeskills

The plugin page is at plugins/sdd. The site home has the Claude Code, Cursor, and Codex variants.

Do not run “init” on the wrong repo. The project is ~/projetos/meu-primeiro-site (Marina’s).

Checklist

  • sdd@freeskills shows in the plugin list.
  • You know this does not publish the site by itself.
  • The folder open in the tool is Marina’s.

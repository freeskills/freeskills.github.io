6.5

Implement from the spec Implementar a partir da spec

The loop you learned in module 1, now with a spec on the table. O ciclo do módulo 1, agora com a spec na mesa.

Introdução

A IA implementa o que está escrito. Você testa o que a spec chamou de Done. Se o visual sair do sistema, a Skill puxa de volta. Se nascer um CRM, a spec e o DNA puxam de volta.

O que você vai aprender

  • Pedir implementação sem alargar o escopo.
  • Três testes manuais (senha errada, cadastrar, remover).
  • O que fazer depois que o guia acaba: o site da Marina continua.

Por que isso importa

Done não é “a IA disse que acabou”. Done é a Marina cadastrar um apto no admin e ele aparecer no catálogo público.

Pedido

Prompt

Spec "Área administrativa de imóveis" aprovada. Skill marina-imovel (só visual) + DNA no repo.

Implemente SÓ o que a spec pede:

- /admin com senha simples (erro visível se errar).
- Lista, cadastro, edição e remoção de imóveis.
- Persistir no data/imoveis.json (ou o mecanismo que a spec definiu).
- O catálogo público atualiza depois de gravar.
- Nada de CRM, nada de pedido de visita, nada de novo framework neste recorte.

Antes de editar: liste os arquivos. Depois pare para eu testar:
1) senha errada
2) cadastrar um apto e ver no catálogo
3) remover e confirmar que sumiu
Definition of Done = esses três testes no navegador.

O guia fecha. O produto não

Você foi da pasta vazia à área administrativa especificada. A Marina cadastra estoque nela, não no chat. O método é o mesmo: entender, spec quando a feature tiver mais de um ator, Skill para o jeito, fatia, navegador, publicar de novo (compartilhada ou VPS com Beway).

Se quiser um próximo passo natural: republicar o admin no mesmo domínio (VPS + Beway, se já estiver nesse caminho) e cadastrar um apto de verdade pelo painel.

Checklist

  • Senha errada não entra e mostra erro.
  • Cadastro válido aparece no admin e no catálogo público.
  • Remover some dos dois. Nada fora da spec entrou no código.

Próximo passo

Fim do guia. Continue no mesmo repo. A próxima feature da Marina começa no DNA, não num prompt “faz o resto”.

Introduction

The AI implements what is written. You test what the spec called Done. If the look leaves the system, the Skill pulls it back. If a CRM appears, the spec and the DNA pull it back.

What you will learn

The guide ends. The product does not

You went from an empty folder to a specified admin area. Marina adds inventory there, not in chat. The method stays: understand, spec when the feature has more than one actor, Skill for the way, a slice, the browser, publish again (shared hosting or a VPS with Beway).

A natural next step: republish the admin on the same domain (VPS + Beway, if you are already on that path) and add a real apt from the panel.

Checklist

  • A wrong password does not get in and shows an error.
  • A valid add shows in the admin and on the public catalog.
  • Remove clears both. Nothing outside the spec landed in the code.

Next step

End of the guide. Stay in the same repo. Marina’s next feature starts in the DNA, not in a “build the rest” prompt.

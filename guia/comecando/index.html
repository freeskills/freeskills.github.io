Module 1 Módulo 1

Getting started Começando

This module is the front door of the guide. Before you build a system, you need to know what is required, where to work, and how to ask AI for help without losing control of what is being built. Este módulo é a porta de entrada do guia. Antes de criar um sistema, você precisa saber o que é necessário, onde trabalhar e como pedir ajuda à IA sem perder o controle do que está sendo construído.

Introdução

Muita gente tenta “aprender tudo” antes de escrever a primeira linha, ou pede à IA um produto completo no primeiro prompt. Os dois extremos atrasam. Aqui você monta o mínimo, entende o fluxo de trabalho e só então parte para um projeto.

O que você vai aprender

  • A proposta deste guia e o que a IA não substitui.
  • O que de fato precisa estar pronto no seu computador.
  • Como escolher entre Linux, macOS e Windows (com WSL).
  • Como preparar terminal, Git e editor sem se perder em extensões.
  • Como instalar o Git, configurar identidade e fazer o primeiro commit.
  • Como usar o Claude dentro de um projeto, com contexto e em passos pequenos.

Conteúdos deste módulo

Introduction

Plenty of people try to “learn everything” before writing the first line, or they ask the AI for a complete product in the first prompt. Both extremes slow you down. Here you assemble the minimum, learn the working loop, and only then start a project.

What you will learn

  • What this guide is for, and what AI does not replace.
  • What actually needs to be ready on your computer.
  • How to choose among Linux, macOS, and Windows (with WSL).
  • How to set up a terminal, Git, and an editor without drowning in extensions.
  • How to install Git, set your identity, and make the first commit.
  • How to use Claude inside a project, with context, in small steps.

5.2

Installing Skills in your environment Instalando Skills no ambiente

Two places: the marketplace (plugins) and a SKILL.md inside Marina’s repo. Dois lugares: o marketplace (plugins) e um SKILL.md dentro do repo da Marina.

Introdução

No FreeSkills, o que você instala primeiro é o marketplace. Dali saem plugins (o SDD é o do módulo 6). A Skill do site da Marina pode viver no próprio projeto: um SKILL.md que o Cursor, o Claude Code ou o Codex leem quando a pasta está aberta.

O que você vai aprender

  • Adicionar o marketplace uma vez.
  • Onde colocar a Skill do projeto.
  • Não misturar isso com “instalar um tema” no servidor.

Por que isso importa

Se a Skill só existe num chat velho, o próximo computador não tem o jeito da Marina. Arquivo no repo viaja com o Git.

Marketplace (uma vez)

Cursor / Claude Code

/plugin marketplace add freeskills/marketplace

Confira com /plugin marketplace list. Detalhes por ferramenta estão na home do FreeSkills. Você ainda não precisa instalar o SDD: isso é o módulo 6.

Skill do projeto

No repo da Marina, o lugar comum é uma pasta que o agente já observa, por exemplo skills/marina-imovel/SKILL.md ou .cursor/skills/marina-imovel/SKILL.md, conforme a ferramenta. A Skill guarda o visual. Cadastrar estoque não mora aí.

Plugin do marketplace ≠ Skill do visual. Um é produto compartilhado. O outro é o manual deste site. Cadastro de imóvel é o admin (módulo 6).

Checklist

  • O marketplace FreeSkills está adicionado (ou você sabe o comando).
  • Você escolheu uma pasta no repo para a Skill da Marina.
  • Não instalou nada no servidor da Beway por causa disso.

Próximo passo

Agora use uma Skill (mesmo rascunho) para um ajuste visual, sem incluir linha no JSON.

Introduction

On FreeSkills, the first install is the marketplace. Plugins come from there (SDD is module 6). The Skill for Marina’s site can live in the project itself: a SKILL.md that Cursor, Claude Code, or Codex read when the folder is open.

What you will learn

  • Add the marketplace once.
  • Where the project Skill sits.
  • Do not mix this with “install a theme” on the server.

Why this matters

If the Skill only lives in an old chat, the next computer does not have Marina’s way. A file in the repo travels with Git.

Marketplace (once)

Cursor / Claude Code

/plugin marketplace add freeskills/marketplace

Check with /plugin marketplace list. Per-tool details are on the FreeSkills home. You do not need to install SDD yet: that is module 6.

Project Skill

In Marina’s repo, a common place is a folder the agent already watches, for example skills/marina-imovel/SKILL.md or .cursor/skills/marina-imovel/SKILL.md, depending on the tool. The Skill holds the look. Inventory signup does not live there.

Marketplace plugin ≠ look Skill. One is a shared product. The other is this site’s manual. Listing signup is the admin (module 6).

Checklist

  • The FreeSkills marketplace is added (or you know the command).
  • You picked a repo folder for Marina’s Skill.
  • You did not install anything on the Beway server for this.

Next step

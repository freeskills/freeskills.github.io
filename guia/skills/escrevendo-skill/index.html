5.4

Write a small Skill Escrever uma Skill pequena

Short frontmatter, a few rules, commit it. That is enough. Frontmatter curto, poucas regras, commit. Isso basta.

Introdução

Uma Skill boa é chata de propósito: cores, caminho do JSON, o que não fazer. Deixe o romance fora. O agente precisa de restrição, não de biografia da Marina.

O que você vai aprender

  • A estrutura de um SKILL.md.
  • O que colocar (e o que deixar no decisoes.md).
  • Como versionar a Skill junto com o site.

Por que isso importa

Skill no Git é o jeito da equipe. Prompt só no chat é o jeito de um dia.

Modelo

SKILL.md

---
name: marina-imovel
description: Regras visuais do site da Marina Alves Corretora. Não use para cadastrar estoque.
---

# Marina Alves Corretora

Site HTML estático. Sem framework.

## Visual
- Fundo #F7F4EF, texto #0B1F33, destaque #2F5D50
- Não use paleta de SaaS roxo nem card com sombra pesada

## Fora de escopo
- Incluir, editar ou apagar imóveis no JSON pelo chat
- Isso é a área administrativa, especificada com SDD no módulo 6

## Regras
- Uma fatia visual por pedido
- CRECI fictício permanece no rodapé
- Respeite docs/decisoes.md

Peça à IA para gravar esse arquivo na pasta que você escolheu, depois abra e corte o que sobrar. Commit: “Skill marina-imovel com visual (sem cadastro no chat)”.

Se a Skill passar de uma tela, ela não vai ser lida. Corte exemplos longos. Uma regra por linha.

Checklist

  • SKILL.md existe no repo e foi commitado.
  • Tem visual, uma proibição (sem SaaS roxo) e deixa cadastro de estoque de fora.
  • O próximo chat pode só dizer “usa a Skill da Marina”.

Próximo passo

Skills aceleram o como. O módulo 6 segura o o quê: a área administrativa para a Marina cadastrar imóveis, com SDD.

Introduction

A good Skill is boring on purpose: colors, the JSON path, what not to do. Leave the novel out. The agent needs constraints, not Marina’s biography.

What you will learn

  • The shape of a SKILL.md.
  • What to put in (and what to leave in decisoes.md).
  • How to version the Skill with the site.

Why this matters

A Skill in Git is the team’s way. A prompt that only lives in chat is one day’s way.

Template

SKILL.md

---
name: marina-imovel
description: Regras visuais do site da Marina Alves Corretora. Não use para cadastrar estoque.
---

# Marina Alves Corretora

Site HTML estático. Sem framework.

## Visual
- Fundo #F7F4EF, texto #0B1F33, destaque #2F5D50
- Não use paleta de SaaS roxo nem card com sombra pesada

## Fora de escopo
- Incluir, editar ou apagar imóveis no JSON pelo chat
- Isso é a área administrativa, especificada com SDD no módulo 6

## Regras
- Uma fatia visual por pedido
- CRECI fictício permanece no rodapé
- Respeite docs/decisoes.md

Ask the AI to write that file in the folder you picked, then open it and cut the extra. Commit: “Skill marina-imovel with look (no signup in chat)”.

If the Skill is longer than one screen, it will not be read. Cut long examples. One rule per line.

Checklist

  • SKILL.md exists in the repo and is committed.
  • It has look, one ban (no purple SaaS), and leaves inventory signup out.
  • The next chat can just say “use Marina’s Skill”.

Next step

Skills speed up the how. Module 6 holds the what: the admin area so Marina can add listings, with SDD.

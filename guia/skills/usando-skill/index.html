5.3

Use a Skill on Marina’s site Usar uma Skill no site da Marina

One visual slice. The Skill carries the rules. You do not add a listing in the JSON. Uma fatia visual. A Skill carrega as regras. Você não cadastra imóvel no JSON.

Introdução

Se a Skill ainda não existe, escreva um rascunho de cinco linhas na pasta combinada (a próxima lição completa o arquivo). O pedido abaixo assume que o agente segue o visual, não inventa um cadastro no JSON. Incluir estoque é a área admin do módulo 6.

O que você vai aprender

  • Como apontar para a Skill sem recontar o romance.
  • Uma fatia visual, sem linha nova no JSON.
  • Como recusar se a IA “ajudar” cadastrando um apto.

Por que isso importa

O valor aparece quando um ajuste de página nasce no mesmo sistema. Se a IA incluir um sétimo apto no JSON, ela errou o recorte: isso é tela da Marina, com SDD.

Pedido

Prompt

Você tem (ou vai ter) a Skill do projeto da Marina Alves. Siga o visual #F7F4EF / #0B1F33 / #2F5D50, sem framework, CRECI no rodapé.

Tarefa única: NÃO cadastre imóvel no JSON.

Na página de um imóvel que já existe, melhore só a hierarquia (título, preço, botão WhatsApp). Não crie listing novo. Não mexa no catálogo inteiro. Não adicione linha em data/imoveis.json.

Antes de editar, diga o que vai mudar. Depois eu reviso no navegador.

Se a IA redesenhar a home, pare. Peça para reverter e releia a Skill com ela, em voz alta, antes do segundo take.

Checklist

  • O JSON tem o mesmo número de imóveis de antes.
  • A página do apto ficou mais clara, no visual da Marina.
  • A IA não “ajudou” criando um listing novo.

Próximo passo

Agora escreva a Skill de verdade: um SKILL.md que o próximo chat não precise adivinhar.

Introduction

If the Skill does not exist yet, write a five-line draft in the folder you picked (the next lesson finishes the file). The ask below assumes the agent follows the look, and does not invent a JSON signup. Adding inventory is the admin in module 6.

What you will learn

  • How to point at the Skill without retelling the novel.
  • One visual slice, no new JSON row.
  • How to refuse if the AI “helps” by adding an apt.

Why this matters

The value shows when a page tweak is born in the same system. If the AI adds a seventh apt to the JSON, it missed the cut: that is Marina’s screen, with SDD.

The ask

Prompt

Você tem (ou vai ter) a Skill do projeto da Marina Alves. Siga o visual #F7F4EF / #0B1F33 / #2F5D50, sem framework, CRECI no rodapé.

Tarefa única: NÃO cadastre imóvel no JSON.

Na página de um imóvel que já existe, melhore só a hierarquia (título, preço, botão WhatsApp). Não crie listing novo. Não mexa no catálogo inteiro. Não adicione linha em data/imoveis.json.

Antes de editar, diga o que vai mudar. Depois eu reviso no navegador.

If the AI redesigns the homepage, stop. Ask to revert and reread the Skill with it, out loud, before the second take.

Checklist

  • The JSON has the same listing count as before.
  • The apt page is clearer, in Marina’s look.
  • The AI did not “help” by creating a new listing.

Next step

Now write the Skill for real: a SKILL.md the next chat does not have to guess.

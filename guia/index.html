Introdução

Este guia é o ponto de partida para quem quer criar software com ajuda de IA. Ele funciona sozinho, como documentação, e também como material complementar de uma série de vídeos.

Você não precisa dominar todas as tecnologias antes de começar. Também não deve entregar todas as decisões para a IA. O caminho do meio é o que funciona: aprender enquanto constrói.

Entender o problema → planejar → utilizar IA → implementar → testar → evoluir.

O que você vai aprender

  • O que precisa ter no computador para começar sem se perder em ferramentas.
  • Como escolher um ambiente de desenvolvimento e preparar o básico.
  • Como usar o Claude (e ferramentas parecidas) dentro de um projeto real.
  • Um jeito incremental de pedir ajuda à IA, em vez de pedir “o sistema inteiro”.

Por que isso importa

IA acelera quem já sabe o que está tentando fazer. Sem um mínimo de método, o resultado costuma ser código que você não entende, não consegue testar e não consegue evoluir.

Introduction

This guide is the starting point if you want to build software with AI. It works on its own as documentation, and also as companion material for a video series.

You don't need to master every technology before you start. You also should not hand every decision to the AI. The middle path is the one that works: learn while you build.

Understand the problem → plan → use AI → implement → test → iterate.

What you will learn

  • What actually needs to be on your computer so you can start without drowning in tools.
  • How to choose a development environment and set up the basics.
  • How to use Claude (and similar tools) inside a real project.
  • An incremental way to ask AI for help, instead of asking for “the whole system”.

Why this matters

AI speeds up people who already know what they are trying to do. Without a little method, you get code you don't understand, can't test, and can't evolve.

Modules

All six modules are live. From the environment to SDD, the same project: the Marina Alves Corretora site. Each lesson has its own URL.

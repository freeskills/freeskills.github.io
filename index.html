Step 1

Install the marketplace

Do this once per tool. After that, FreeSkills plugins appear in your marketplace catalog.

Claude Code

In an interactive Claude Code session:

/plugin marketplace add freeskills/marketplace

Or via CLI:

claude plugin marketplace add freeskills/marketplace

Confirm with /plugin marketplace list.

Cursor

  1. Open Dashboard → Plugins.
  2. Under Team Marketplaces, click Add Marketplace.
  3. Import https://github.com/freeskills/marketplace.
  4. Save, then install plugins from Customize.

CLI (Cursor Agent):

cursor-agent plugin marketplace add https://github.com/freeskills/marketplace

Then use /plugin → Marketplace to install.

Codex

codex plugin marketplace add freeskills/marketplace

Optional pin:

codex plugin marketplace add freeskills/marketplace --ref main

In ChatGPT/Codex (Work mode), open Plugins and select the FreeSkills source.

Step 2

Install a plugin

After the marketplace is added, install only what you need. Browse the full catalog for details and commands.

sdd

Step 3

Keep everything updated

Refresh the marketplace catalog when new plugins land, then update installed plugins.

Claude

/plugin marketplace update freeskills
/plugin update sdd@freeskills

Cursor

  1. Open Dashboard → Plugins.
  2. Refresh the FreeSkills marketplace (or wait for auto-refresh).
  3. Update sdd in Customize.

Codex

codex plugin marketplace upgrade freeskills
codex plugin marketplace list

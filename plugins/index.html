FreeSkills

Skills for agents. One marketplace. Skills para agentes. Um marketplace.

Add FreeSkills to Cursor, Claude Code, or Codex. Then install plugins and keep them current without hunting repos by hand. Adicione o FreeSkills ao Cursor, Claude Code ou Codex. Depois instale plugins e mantenha-os atualizados sem caçar repositórios na mão.

Step 1 Passo 1

Install the marketplace Instale o marketplace

Do this once per tool. After that, FreeSkills plugins appear in your marketplace catalog. Faça isso uma vez por ferramenta. Depois, os plugins do FreeSkills aparecem no catálogo do marketplace.

Claude Code

In an interactive Claude Code session: Em uma sessão interativa do Claude Code: 

/plugin marketplace add freeskills/marketplace

Or via CLI: Ou via CLI: 

claude plugin marketplace add freeskills/marketplace

Confirm with /plugin marketplace list. Confirme com /plugin marketplace list.

Cursor

  1. Open Dashboard → Plugins. Abra Dashboard → Plugins.
  2. Under Team Marketplaces, click Add Marketplace. Em Team Marketplaces, clique em Add Marketplace.
  3. Import https://github.com/freeskills/marketplace. Importe https://github.com/freeskills/marketplace.
  4. Save, then install plugins from Customize. Salve e instale plugins em Customize.

CLI (Cursor Agent): CLI (Cursor Agent): 

cursor-agent plugin marketplace add https://github.com/freeskills/marketplace

Then use /plugin → Marketplace to install. Depois use /plugin → Marketplace para instalar.

Codex

codex plugin marketplace add freeskills/marketplace

Optional pin: Pin opcional: 

codex plugin marketplace add freeskills/marketplace --ref main

In ChatGPT/Codex (Work mode), open Plugins and select the FreeSkills source. No ChatGPT/Codex (modo Work), abra Plugins e selecione a fonte FreeSkills.

Step 3 Passo 3

Keep everything updated Mantenha tudo atualizado

Refresh the marketplace catalog when new plugins land, then update installed plugins. Atualize o catálogo do marketplace quando novos plugins chegarem e depois atualize os plugins instalados.

Claude

/plugin marketplace update freeskills
/plugin update sdd@freeskills

Cursor

  1. Open Dashboard → Plugins. Abra Dashboard → Plugins.
  2. Refresh the FreeSkills marketplace (or wait for auto-refresh). Atualize o marketplace FreeSkills (ou espere o auto-refresh).

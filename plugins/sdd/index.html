sdd · v1.0.6

Spec-Driven Development

Architecture-first engineering for AI assistants. Keep project knowledge in .specs/, decide with ADRs, and run protocol commands from init through finish. Engenharia com arquitetura em primeiro lugar para assistentes de IA. Mantenha o conhecimento do projeto em .specs/, decida com ADRs e rode os comandos de protocolo do init ao finish.

  • Architecture Arquitetura
  • Specs
  • AI workflow Fluxo com IA
  • Auth defaults Padrões de auth

What you get O que você recebe

  • Living project knowledge: DNA, vision, architecture, modules, ADRs, tasks Conhecimento vivo do projeto: DNA, visão, arquitetura, módulos, ADRs, tarefas
  • Command cycle: init → new → plan → start → finish Ciclo de comandos: init → new → plan → start → finish
  • Quality gates: status, doctor, sync, review Gates de qualidade: status, doctor, sync, review
  • Opinionated defaults for modules, Inbox/Outbox, migrations Padrões opinativos para módulos, Inbox/Outbox e migrações
  • Auth split: app frontends use HttpOnly/Secure/SameSite cookies (or BFF); direct API clients may use Bearer, API keys, mTLS, etc. Auth: frontends da aplicação usam cookies HttpOnly/Secure/SameSite (ou BFF); clientes de API diretos podem usar Bearer, API keys, mTLS etc.

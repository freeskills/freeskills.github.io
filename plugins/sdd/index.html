sdd · v1.0.6

Spec-Driven Development

Architecture-first engineering for AI assistants. Keep project knowledge in .specs/, decide with ADRs, and run protocol commands from init through finish.

  • Architecture
  • Specs
  • AI workflow
  • Auth defaults

What you get

  • Living project knowledge: DNA, vision, architecture, modules, ADRs, tasks
  • Command cycle: init → new → plan → start → finish
  • Quality gates: status, doctor, sync, review
  • Opinionated defaults for modules, Inbox/Outbox, migrations
  • Auth split: app frontends use HttpOnly/Secure/SameSite cookies (or BFF); direct API clients may use Bearer, API keys, mTLS, etc.
